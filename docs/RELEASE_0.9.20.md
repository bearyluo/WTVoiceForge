# WT Voice Forge 0.9.20

首次 GitHub 预发布，面向 Windows 10/11 x64。

## 功能

- 工作台按“添加素材 → 训练音色 → 生成语音 → 应用到游戏”组织制作流程。
- 支持 GPT-SoVITS 中文配音、RVC 原语言换声及已有模型导入。
- 支持逐句编辑、原音对比、连续试听、重新生成、现成 WAV 导入和语气/语速/音量调整。
- 支持通用、空战、陆战、海战和座舱声音选择；当前覆盖 61 张乘员表。
- 支持语音包导出、安装前备份、冲突提示、卸载恢复、RAR / 7z 导入及包内查看。
- 环境准备页提供运行时下载、空间检查和本地缓存清理。

## 下载

- 安装版：`WTVoiceForge-Setup-0.9.20.exe`。
- 绿色版：`WTVoiceForge-Portable-0.9.20.zip`，解压后运行 exe，保留随附许可证。
- `SHA256SUMS.txt` 提供发布文件校验值。

程序包不包含用户项目、录音、训练模型、游戏音频、GPT-SoVITS / RVC 运行时或官方 FMOD 工程。首次使用需要按环境准备页补齐相应组件。

## 已知限制

- 安装包尚未签名，Windows 可能显示未知发布者或 SmartScreen 提示。
- 游戏内全场景实听、RVC 跨语言人耳评分尚未完成；自动测试通过不等于游戏内验收通过。
- 海战中文是首轮译文，需要听原音校对，目前没有官方中文海战表可直接使用。
- 同 bank 的已编译语音包不做二进制合并，安装前需要检查冲突。
- 软件内卸载时如需保留项目和模型，请勾选“保留 data 文件夹”。
